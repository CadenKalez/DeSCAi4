# none: all 25 hand-written functions are written from their decompilation. The seam the app still has to hook up is
# IWinAnimationRecorderHost (set with SetWinAnimationRecorderHost): the font (RZ::FO vslot 0x48 over cIGZFontSys::FontAcquire,
# as a gz::IWinFont), the frame buffers (RZ::GS vslot 0x20, one reference each), the colour-buffer extension
# (SL::spGDriver QueryInterface(0xe69bfe2a), one reference held at +0x230 and released by Shutdown), the animation tick
# manager (service 0x86ad10ec / iid 0x86ad10ed, borrowed: vslots 0x60 PauseAnimationSystem, 0x78 SetStepTickTimeDelta,
# 0x80 StepAnimationSystem), the Gimex factory (SL::spSC4 vslot 0x148, its vslot 0x30 SaveToFile folded into one SaveImage
# call so a missing factory and a failed save look the same), the application paths (SL::spSC4 vslots 0xe8 / 0x188), the
# window control manager (RZ::WCM), the location saver (SL::spWinLocationSaver / cSLWinLocationSaver) and the 3D view
# window (SL::spView3DWin). Without the host the window still builds (no controls) and every recording entry point refuses.
# Deviations noted in the source: the animation tick manager is borrowed rather than owned (the original holds a
# cRZSysServPtr for the call); the dialogs / edits / math guards that the original does not have (null controls, a zero
# capture rectangle, a zero frame interval) keep the port out of undefined behaviour; FixAnimationName uses the C library's
# isalnum / isspace on the unsigned byte instead of the original's __maskrune table (identical for ASCII); the output type
# read from the ini (+0x2d0) is never applied to the option group, as in the original.
