SimCity 4: Known Bugs and Why They Happen

Compiled for the SC4-Decomp native Metal port · 14 Oct 2026 · Game: SimCity 4 Deluxe (Aspyr macOS v1.2.1)
How to read this. Each entry gives symptom, cause, fix known to the community, and a confidence tag. sourced = stated by the cited source with a mechanism; partial = symptom and fix are sourced, mechanism is inferred; unverified = anecdotal. Causes marked "inferred" are my reasoning from data/behaviour, not from decompiled code, because most of the relevant simulator code in this port has not been recovered yet. Sources are listed at the end.

1. Sims take the shortest route, not the fastest partial

Symptom. Commuters pile onto a single short road next to a highway; gridlock while parallel capacity sits idle. Rush Hour did not change it.

Cause. The route search weighs path length and not travel time or congestion, so every agent between the same endpoints chooses the same edge. Because all agents reach the same decision independently, road capacity is never used as feedback. Community write-ups state this behaviour; the choice of a length-only cost is the inference.

Fix. Network Addon Mod (NAM) replaces the pathing with a speed-aware search. Port note: our traffic pathfinder will expose the edge cost as a function so a time-weighted option can be A/B tested without changing results by default.

2. "Eternal Commuter" regional loop partial

Symptom. Sims bounce between cities looking for work without ever taking a job. Zone demand collapses, traffic grows without bound, economy decays.

Cause. Regional pathfinding across city boundaries, in particular layouts, lets a commuter be rejected at the destination and re-queued toward another neighbour with no memory that it already tried. No termination condition exists in a cycle of cities. (Stated mechanism: regional pathfinding across city boundaries in certain layouts. The "no memory / no termination" detail is inferred.)

Fix. NAM update 50 (August 2026) blocks specific neighbour-to-neighbour routes. Before it, the only workaround was to avoid layouts that allow loops.

3. Industrial High-Tech cannot employ top-wealth Sims sourced

Symptom. High-tech industry creates demand for $$$ workers, yet almost no $$$ jobs are filled.

Cause. The job table gives the three wealth bands the ratio 10:80:10. Two entries have identical values, and the game ignores one of the equal values, so the $$$ share is dropped. This is a tie-handling error in the ratio data, not a missing building.

Fix. IH_census_10_78_12.dat changes the numbers so no two are equal.

4. Medical clinic, solar plant and nuclear plant jobs sourced

Symptom. Same as #3: a wealth bracket's jobs never fill.

Cause. Same duplicate-value defect in “Demand Created”: clinic $1/$$6/$$$1, solar $10/$$12/$$$10, nuclear $20/$$20/$$$8.

Fix. HT_DemandFix.dat: clinic 2/5/1, solar 11/12/9, nuclear 22/18/8.

5. Opera House lowers education when the city grows sourced

Symptom. A growing city sees its education rating fall after an Opera House is built.

Cause. The building's capacity is fixed at 1,200 and the building is counted as “underfunded” once usage exceeds it, which feeds a negative term into city-wide education, and there is no way to give it extra funding.

Fix. The Bugfix Bundle raises the cap to 25,000 and scales cost with capacity. Existing Opera Houses must be bulldozed first or the game may crash.

6. Private Schools overcrowding partial

Symptom. Education falls when a private school exceeds about 1,000 students within its radius.

Cause. Same over-capacity penalty mechanism as the Opera House (#5).

7. Space Port promises a High-Tech boost that was never implemented sourced

Cause. The description text promises the effect, but no High-Tech Industry cap effect exists in the building data; it only adds cost and slight commercial desirability.

Fix. Plugin adds 150,000 High-Tech Industry cap relief.

8. Crime does not drop with more police partial

Symptom. Crime stays high even with police stations everywhere.

Cause. Not documented by the source; the plugin changes the data so additional stations reduce crime. Mechanism unknown.

9. Farley's Foundry: unlimited industrial zone from one road partial

Symptom. A 2x1 seed building plus 1x1 additions lets an industrial block grow far beyond the normal road-connection range; fires inside it may get no truck response.

Cause. Road adjacency appears to be tested for the seed lot only, and the additions inherit the seed's type and are treated as one large building. (Described by the discoverer; the exact check is inferred.)

10. Mayor rating oddities unverified

Symptom. Ratings stuck near 60% or swinging by large amounts; negative ratings unreachable.

Cause. Forum evidence points to lots categorised wrongly (a mod's seawall lots counted as Transportation/Water and carrying a large rating effect). The floor on negative ratings is reported but not explained.

12. Save-file graphics corruption at custom resolutions unverified

CodeWeavers reports corruption along the lower edges of the city when saving at higher custom resolutions (also on Windows). The save thumbnail/preview is probably rendered from the live framebuffer at the active size, which would explain it; this is inferred.

What this means for the port

  • Keep original behaviour as the default so saved cities match; expose each fix as a switch (bundle data patches, pathing cost, loop guard).
  • As the traffic, job and capacity code is recovered, each entry's inferred mechanism will be replaced with the verified code path.
  • The data-only bugs (#3, #4, #5, #7) can be reproduced and verified right now by reading the exemplar tables from the game's DBPF files.
